# Vanilla Redux

A balance overhaul mod for [Balatro](https://store.steampowered.com/app/2379780/Balatro/). Many jokers and other elements have been reworked and updated — familiar tactics require rethinking, and new strategies emerge. Each run feels fresh and the gameplay becomes more intense.

## Features
- Updated and reworked 75 reworked vanilla jokers, 6 spectral and 2 tarot

## Requirements
- [Steamodded](https://github.com/Steamodded/smods) ≥ `1.0.0-beta-1620a`
- [Lovely](https://github.com/ethangreen-dev/lovely-injector) ≥ `0.9.0`

## Compatibility
Tested with vanilla Balatro and [Talisman](https://github.com/MathIsFun0/Talisman). Other mods may cause conflicts — please report incompatibilities via [Issues](../../issues).

## Installation
1. Install [Steamodded](https://github.com/Steamodded/smods) and [Lovely](https://github.com/ethangreen-dev/lovely-injector).
2. Download the latest release `.zip` from the [Releases](../../releases) page.
3. Extract the `VanillaRedux` folder into your Balatro mods directory:
   ```
   %APPDATA%/Balatro/Mods
   ```
4. **Updating:** delete the old `VanillaRedux` folder, then extract the new version.
5. **Uninstall:** delete the `VanillaRedux` folder from `Mods`.
