# Changelog

## 1.1.0

### General
- Added a custom mod icon.

### Balance
- **Fibonacci**: Now also triggers on **Kings**. Mult increased from +13 to **+21**.
- **Steel Joker**: X Mult per Steel Card held in hand reduced from X0.75 to **X0.5**.
- **Scholar**: Reworked. Gains **+4 Mult** when the shown poker hand is played with a scoring **Ace**, then the hand changes. Aces no longer give Mult on their own.
- **Faceless Joker**: Rarity reverted from Uncommon to vanilla **Common**.
- **Ancient Joker**: Stone Cards no longer give X1.25 Mult. They still count as the same rank.
- **Matador**: Boss Blind payout increased from $12 to **$16**.

### Joker Fixes
- **Four Fingers**: Fixed the 4-card limit not coming back after being debuffed.
- **Credit Card**: Debt limit stays at -$20 with multiple copies. The free purchase is no longer wasted if buying fails. Fixed the Buy button overlapping "Buy and Use".
- **Marble Joker**: Added Stone Cards now count for Hologram. Can now be copied by Blueprint and Brainstorm.
- **8 Ball**: Fixed a crash after all triggers were used. Blueprint, Brainstorm and Abstract Joker now use their own counter.
- **Abstract Joker**: Can no longer pick a Joker that is being destroyed. Keeps copying its target until end of round, even if it gets destroyed or you reload the game. Fixed a crash with Jokers from other mods.
- **Delayed Gratification**: Gift Card bonus to sell value is no longer lost.
- **Pareidolia**: Rank changes now follow the run seed. Stone Cards no longer count as face cards.
- **Runner**: Gives its Chips on every hand, like in vanilla. Each Straight increases the gain by +5.
- **Sixth Sense**: Removed the leftover vanilla effect and the jiggle before the first hand.
- **Faceless Joker**: Fixed a crash on discard. Face cards are debuffed or restored right away when it is bought or sold.
- **Red Card**: Now works correctly with Four Fingers. No longer triggered by The Hook.
- **Seance**: Removed the leftover vanilla effect.
- **Reserved Parking**: Tooltip chance now updates with Oops! All 6s.
- **Golden Joker**: Fixed a crash with Jokers from other mods.
- **Baseball Card**: Two Baseball Cards no longer boost each other.
- **Bull**: Each copy keeps its own value, a new one starts at 0. Fixed tooltip bugs.
- **Flash Card**: Removed the leftover vanilla effect.
- **Mr. Bones**: Removed the leftover vanilla effect. After saving you, it no longer blocks the next sale or destruction.
- **Throwback**: Each copy counts its own skips, a new one starts at 0.
- **Flower Pot**: With Smeared Joker, each card now counts as only one suit.
- **Matador**: Fixed a crash when a Boss Blind ability triggers.
- **Hit the Road**: X Mult no longer resets at the end of each round.
- **Satellite**: Tooltip now matches the payout.
- **Bootstraps**: Each copy keeps its own value, a new one starts at 0. Fixed tooltip bugs.

### Spectral Cards
- **Familiar**, **Incantation**: Destroyed cards now count for Canio and Glass Joker, like in vanilla.
- **Ouija**: Each use is a separate -1 hand size for 3 rounds. A second Ouija now stacks.
